Nasıl Kullanılır?
1. Yeni Proje → 2. Kaynak/Şablon → 3. Builder → 4. Preview → 5. Build → 6. Test Lab → 7. Production.

        
Google Play Yayın Rehberi
AAB üret, imzalama bilgilerini doğrula, Test Lab sonucunu kontrol et, Production Center'da release notlarını hazırla ve Play Console'a yükle.

        
Platform Notları
Google Play satın alma, Android runtime permission isteme ve cihaz FCM tokenı Android'e özeldir. Windows/Web bunların proje yapılandırmasını yönetir.

        
Destek
Build hatasında Build Kontrol → Canlı Log ve Test Lab sonuçlarını kullan. AI Asistan hata loglarını güvenli şekilde yorumlar.
