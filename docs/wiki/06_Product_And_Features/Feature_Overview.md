# Feature Overview

AppForge Studio groups several developer workflows in one product:

- project scaffolding and Studio UI
- preview/test tooling
- Android APK/AAB build and analysis
- Play preparation/release concepts
- embedded Terminal, files, Git, SSH, and runtime tools
- GitHub/Railway connection support
- local AI assistant
- PWA/native/production inspection tools
- build comparison and release notes

Feature memory should describe stable behavior, not duplicate every UI label.
