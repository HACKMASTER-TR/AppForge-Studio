# AppForge Studio v2.1 — Advanced Template Browser

The Templates area in the Android client has been redesigned into a richer category browser.

## New behavior

- category-first template browsing
- eight visually distinct template categories
- template/category search
- template counts per category
- top stats card
- category detail bottom sheet
- template apply action directly inside category details
- usable even before login (catalog visible, remote templates require login)

## Categories

- Etkileşim
- Başlangıçlar
- Starter Libraries
- Reklamlar
- Cihaz
- Sensörler
- Sistem
- Panel

## Mapping

Remote templates are normalized into the visual categories using template:
- category
- name
- description

keyword matching.

## UX notes

The screen is inspired by a compact mobile template-store layout, but integrated into the existing AppForge navigation and server-backed template system.
