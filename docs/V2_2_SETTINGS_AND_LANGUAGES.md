# AppForge Studio v2.2 — Settings + Languages

v2.2 adds a full settings hub, advanced support/legal screens, a local keystore vault, and multi-language support.

## New screens

- Settings hub
- Language selector
- Legal center
- How-to-use center
- Play publishing guide
- Pro upgrade screen
- Keystore manager

## Language support

Included language options:
- system default
- Turkish
- English
- German
- Arabic

The language system is lightweight and currently targets the new settings/support areas.

## Keystore Vault

Imported keystores are copied into private app storage and indexed locally.
Stored metadata includes:
- display name
- original file name
- saved path
- SHA-1
- SHA-256
- added timestamp

## Settings actions

- language selection
- keystore manager
- Pro center
- how-to-use
- Play Store guide
- legal center
- send feedback
- clear temporary cache
