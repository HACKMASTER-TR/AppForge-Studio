# Local Termux build driver
Candidate-only, user device ARM64. Uses existing Ubuntu PRoot/JDK21/Gradle9.3.1/SDK37 and original signing key; never pushes, installs or publishes. Preflight has no APK build or password prompt. Full build requires pinned commit, explicit profile/version/test count, native source/config equivalence to v585 and verified v586 native bytes. Stops on native changes, unreviewed profile, dirty tracked source, mismatched test count, wrong signature or different existing output. Absolute paths restore Gradle source before the success sentinel. Snapshot regenerated locally; synchronize it separately before cloud CI. Device validation pending; no claim of new APK or cloud CI. Existing native inputs remain local; this does not build native code from scratch. For fresh install bootstrap and portable multi-device paths a future separate stage is needed.
